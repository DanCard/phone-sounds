# What setup-phone.sh applies to a phone. One rule per line, fields split by "|".
# Lines that don't apply (app not installed, channel not created yet) are
# reported as PENDING, not errors; re-run after opening/signing in to the app.
#
#   enable  | <package>
#       Turn the app's notifications on (grants POST_NOTIFICATIONS).
#   channel | <package> | name:<channel name> or id:<channel id> | <sound title>
#       Give every live channel that matches this notification sound. Match by
#       NAME where possible: IDs differ per phone and some apps rotate them
#       (Signal messages_1 -> messages_2, Messenger @<uuid>, Google Voice 1TXT/2TXT,
#       Google Chat one channel per account). Off channels get turned on.
#   contact | <contact name, E.164 phone number, or *> | <ringtone title>
#       Per-contact ringtone for regular phone calls. Matching by contact name
#       sets the ringtone on every contact entry with that name (handy when
#       SIM cards/numbers change). "*" sets a fallback ringtone on all contacts
#       not matched by a specific contact rule.
#   default | notification or ringtone | <sound title or None>
#       Phone-wide default notification sound / ringtone (ringtone also sets SIM 2;
#       "None" or "Silent" silences the default so unknown callers do not ring).
#   manual  | <text>
#       Something no script can set; printed as a checklist at the end.
#
# Any rule can end with "| only:<text>": it then applies only to phones whose
# serial, maker or model contains <text> (e.g. only:samsung, only:pixel).
#
# PRIVATE rules (contact lines with phone numbers) go in phone-config.local.txt
# next to this file: same format, git-ignored, read after this file.
# See phone-config.local.example.txt.
#
# Sound titles are file names without extension, from notifications/ (notification
# sounds) or ringtones/ (ringtones). All of both folders gets pushed.
